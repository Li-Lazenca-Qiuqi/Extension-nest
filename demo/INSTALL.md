# Extension Nest Demo

版本：0.2.0。需要 VS Code 1.137.0 或更新版本。

在 VS Code 原生 Extension Nest 侧边栏整理分组，在编辑器 Dashboard 查看与操作示例插件。不包含自建网页侧边栏。

安装后运行命令 `Extension Nest Demo: Open Extension Nest Dashboard`。也可点击活动栏的 Extension Nest 图标，再点击分组视图标题上的 Dashboard 图标。

- 原生树支持插件拖动到分组、拖动组排序。
- Dashboard 支持鼠标选择、移组、状态筛选、搜索与模拟管理。
- 14 个插件均为示例数据；启用、禁用、更新不会改动真实插件。
- Tag 支持多个，仅用于筛选与搜索；编辑标签不改变 Group。
- 不提供配置导入导出或插件卸载。
- Reset Demo 可恢复原始演示状态。

当前仅为本地交互 Demo，不是正式 Marketplace 发布版本。
