# Extension Nest Demo

版本：0.1.0。需要 VS Code 1.137.0 或更新版本。

在 VS Code 原生 Explorer 侧边栏整理分组，在编辑器 Dashboard 查看与操作示例插件。不包含自建网页侧边栏。

安装后运行命令 `Extension Nest Demo: Open Extension Nest Dashboard`。也可在 Explorer 中找到 Extension Nest Demo，点击标题上的 Dashboard 图标。

- 原生树支持插件拖动到分组、拖动组排序。
- Dashboard 支持鼠标选择、移组、状态筛选、搜索与模拟管理。
- 14 个插件均为示例数据；启用、禁用、更新、卸载不会改动真实插件。
- Reset Demo 可恢复原始演示状态。

当前仅为本地交互 Demo，不是正式 Marketplace 发布版本。
