## 1. 目标与需求

| 编号 | 功能 | 必须满足的行为 |
| --- | --- | --- |
| F05 | 单组分配 | 批量选择和菜单分配到唯一目标；已有归属被替换；可解除归属；不能保存多个组 ID |

## 2. 规则与交互

每个 Extension ID 至多对应一个 Group ID，未分配即 Ungrouped。菜单或卡片分组入口将已有归属替换为唯一目标；同目标操作幂等。Dashboard 复选框支持纯鼠标批量选择，批量操作说明目标和受影响数量，并一次性提交；失败不产生部分移动。分组分配或解除只更新 `groupId`，不读取、追加或清空扩展的 Tag。
