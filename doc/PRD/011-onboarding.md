| 编号 | 功能 | 必须满足的行为 |
| --- | --- | --- |
| F11 | 首次引导 | 无组时引导 Create Group 和鼠标选择插件；取消保留空组；所有核心命令有可点击入口 |

## 2. 规则与交互

没有用户组时提供可点击 Create Group；首次创建后引导鼠标选择插件，取消选择保留空组。所有核心操作有鼠标入口；键盘导航仅辅助。区分无分组、筛选无结果、确认无安装、读取失败，不能将错误描述为没有安装。
