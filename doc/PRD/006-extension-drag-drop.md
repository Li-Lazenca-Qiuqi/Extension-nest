## 1. 目标与需求

| 编号 | 功能 | 必须满足的行为 |
| --- | --- | --- |
| F06 | 插件拖动 | 拖入目标组即移动、拖入 Ungrouped 即移出；批量移动一次写入；失败恢复原分组，不留下重复或半完成关系 |

## 2. 规则与交互

插件拖动只在原生 TreeView 内完成；Dashboard 使用卡片移组和批量移动入口。拖放与菜单移动复用同一归属服务，禁用插件仍可拖动。悬停突出有效目标并显示 Move to…；外部载荷不得执行。

从 A 拖入 B，单次提交把归属从 A 改为 B；A 数量减少，B 增加。重复拖入当前组不改变数据。批量分配会移动已归类的扩展，确认界面说明受影响数量；普通拖动本身就是明确移动，不再追加确认。移动只改变 `groupId`，保留原有 Tag 数组。

将插件拖到 Ungrouped 清除归属。拖到空白、扩展叶子或不支持的外部载荷不写状态。拖动组只改变组顺序，不创建嵌套组。根据用户要求，分组拖放在真实 VS Code TreeView 内完成；Dashboard 提供行内和批量移动入口，不复制侧边栏或依赖跨面板拖放。
