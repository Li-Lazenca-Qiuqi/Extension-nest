## 1. 目标与需求

| 编号 | 功能 | 必须满足的行为 |
| --- | --- | --- |
| F06 | 插件拖动 | 拖入目标组即移动、拖入 Ungrouped 即移出；批量移动一次写入；失败恢复原分组，不留下重复或半完成关系 |

## 2. 规则与交互

原生 TreeView 和 Dashboard 分组卡片均支持插件拖动。Dashboard 卡片可拖入组标题、组内容区或空组，分组区域不增加大块高亮或边框；多选后拖动选中卡片会移动全部选中插件。拖放与菜单移动复用同一归属服务，禁用插件仍可拖动。拖动时仅降低源卡片透明度，保持原尺寸、圆角和布局，不显示 Move here 覆盖提示；外部载荷不得执行。

从 A 拖入 B，单次提交把归属从 A 改为 B；A 数量减少，B 增加。重复拖入当前组不改变数据。批量分配会移动已归类的扩展，确认界面说明受影响数量；普通拖动本身就是明确移动，不再追加确认。移动只改变 `groupId`，保留原有 Tag 数组。

将插件拖到 Ungrouped 清除归属。拖到空白、扩展叶子或不支持的外部载荷不写状态。拖动组只改变组顺序，不创建嵌套组。Dashboard 拖放在编辑器的既有分组内容区完成，不增加网页侧边栏；跨 TreeView/Webview 拖放不作为已验证能力。

## 卡片拖动与点击分离

Dashboard 使用单一指针拖动与同尺寸卡片预览，不启用操作系统原生拖影，不提供六点手柄。预览不透明度固定为 0.82，不叠加系统遮罩，保留起拖点偏移。从卡片空白处开始移动；按钮、复选框、Tag 和菜单交互不启动拖放，保持各自功能。
