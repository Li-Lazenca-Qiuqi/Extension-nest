## 2. 规则与交互

原生 TreeView 和 Dashboard 分组卡片均支持插件拖动。Dashboard 卡片可拖入组标题、组内容区或空组；指针拖动期间，目标分组整体显示主题拖放背景和细轮廓，标题、卡片内部及组内空白使用相同高亮，不改变布局。离开目标、放下或取消后清除高亮；多选后拖动选中卡片会移动全部选中插件。拖放使用统一归属服务，历史不可见条目仍可拖动；不提供移组菜单。源卡片保持原尺寸、圆角和布局，拖动透明度为 0.82，不显示 Move here 覆盖提示；外部载荷不得执行。

从 A 拖入 B，单次提交把归属从 A 改为 B；A 数量减少，B 增加。同组无新落点时不改数据，有明确落点时只调整顺序。批量拖动移动全部选中记录，拖动本身就是明确移动，不追加确认。移动只改变正式 `assignments` 及需要的卡片顺序，保留原有 Tag 数组。

原生树中，将插件拖到组标题或该组任一扩展条目，均移动到该组；拖到 Ungrouped 标题或其成员条目均清除归属。组内各条目应提供一致的接收体验；原生悬停反馈由 VS Code 绘制，当前公开 API 无法定制整组高亮，视觉一致性仍需实测。没有命中树节点的空白区域、已失效目标或不支持的外部载荷不写状态。拖动组只在组标题上改变组顺序，不创建嵌套组。Dashboard 拖放在编辑器的既有分组内容区完成，不增加网页侧边栏；跨 TreeView/Webview 拖放不作为已验证能力。

## 卡片拖动与点击分离

Dashboard 使用单一指针拖动与同尺寸卡片预览，不启用操作系统原生拖影，不提供六点手柄。预览不透明度固定为 0.82，不叠加系统遮罩，保留起拖点偏移。从卡片空白处开始移动；按钮、Tag 和菜单交互不启动拖放，保持各自功能。


当前可见、历史不可见与未核验记录使用相同的组织规则；消失/重现不改变 Group、Tag 或保存顺序。标记定义见 [PRD-001](001-installed-inventory.md)，数据新鲜度独立处理。
