## 1. 目标与需求

| 编号 | 功能 | 必须满足的行为 |
| --- | --- | --- |
| F15 | 同步 | 在 VS Code 原生界面外部完成安装/启停/更新，或外部卸载后，两种界面均同步；操作后重新读取真实状态，不只根据点击结果改图标 |

## 2. 规则与交互

宿主是两种 UI 的统一状态源；原生界面中的安装、启停、更新以及外部卸载变化均需只读同步，后台自动更新也需同步。收到可用状态通知后两处更新目标小于 2 秒；事件缺失时在重新聚焦与手动刷新时重读。相同实例的冲突操作应互斥或串行，确认原生结果后才更新成功状态。断连保留最后有效清单并标记 Stale/Offline；多窗口冲突不能静默覆盖。本插件不提供卸载动作。
