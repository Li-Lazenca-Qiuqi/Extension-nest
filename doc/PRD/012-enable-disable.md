## 2. 规则与交互

从原生树或卡片发起启停；多实例先鼠标选择 Local/Remote 目标，再确定原生允许的全局或 Workspace 范围。保留策略、信任、依赖及重启提示，取消任一步不执行。禁用后留在原组并灰显，仍可选择、移组和管理；根据原生返回状态确认结果。

- Enabled：正常主题前景色；Disabled：灰色/降低视觉强调，同时显示 Disabled 文本或标记，仍可点击、拖动和管理。
- Workspace 禁用与全局禁用在 Tooltip 或状态详情区明确标注；因信任、策略、依赖或环境而不可用时显示原生原因，不能冒充用户禁用。
- 未激活不等于禁用。读取失败显示 Unknown；待重启显示 Restart Required，不伪装为已经生效。
- 同一 ID 存在不同环境实例时，组内仍只有一行，状态可显示 Mixed；展开实例选择或在 Dashboard 切换安装目标后查看准确状态。混合状态不整行当成 Disabled。
- Dashboard 确保禁用卡片灰显；原生树的着色方式在 M0 验证，不假定 TreeItem 可任意设置 CSS。若完整行着色不支持，采用主题支持的灰色图标/说明文字及 Disabled 标记，保留可读性。
