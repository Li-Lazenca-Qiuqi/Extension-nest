## 1. 目标与需求

| 编号 | 功能 | 必须满足的行为 |
| --- | --- | --- |
| F07 | 组排序 | 鼠标拖动排序并持久化，另保留 Move Up/Down；Ungrouped 固定；组内默认名称排序，同名用 ID 稳定排序 |

## 2. 规则与交互

原生树拖动组到目标位置，持久化用户组顺序；也提供 Move Up/Move Down 辅助入口，首尾不能越界。Ungrouped 固定，不参与排序或成为嵌套组。组内扩展默认按名称排序，同名按 ID 稳定排序。
