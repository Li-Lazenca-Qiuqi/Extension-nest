## 1. 目标与需求

| 编号 | 功能 | 必须满足的行为 |

| F07 | 组排序 | 鼠标拖动分组排序并持久化，支持 Move Up/Down 与名称升降序；Ungrouped 固定；组内支持名称、publisher、ID 升降序和手动上下移动 |

## 2. 规则与交互

原生树拖动组到目标位置，持久化用户组顺序；也提供 Move Up/Move Down 辅助入口，首尾不能越界。Ungrouped 固定，不参与排序或成为嵌套组。新建演示清单默认按名称排序，同名按 ID 稳定排序；已有快照保留保存的顺序。组内支持按名称、publisher、ID 升降序排列和逐项 Move Up/Down。排序作为一次操作写入快照，不持续强制重排；侧边栏和 Dashboard 使用同一顺序，分组归属和 Tag 不变。Dashboard 分组标题左侧六点抓手支持拖动，整个目标组使用同一落点：向后拖插入目标之后，向前拖插入目标之前；组间空白按最近分组接收，显示主题色插入线；抓手聚焦时方向键支持上下移动。分组标题 Sort 提供组内字段排序，顶部 Sort groups 提供分组名称排序；原生树提供对应菜单。
