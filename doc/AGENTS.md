# 文档库约定

- `TODO.md`：唯一活动待办清单，完成项必须有对应产物或验证证据。
- `Roadmap.md`：阶段和退出条件，不维护与 TODO 重复的勾选状态。
- `PRD/`：需求定义；当前基线为 `PRD/extension-nest.md`。
- `decisions/`：持久有效的取舍、默认解释和后续修订原因。
- `note/`：来源摘要、调研及验证笔记，须区分事实和未验证假设。
- `archive/`：历史资料，默认不访问。

修改范围、行为或验收标准时，同时核对 PRD、决策记录与 TODO 的一致性。不得把聊天助手建议自动标记为用户逐项确认；文档日期不代表产品版本发布。
