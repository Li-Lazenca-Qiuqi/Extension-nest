# 文档库约定

- `PRODUCT.md`：产品定位、现有能力、关键流程、支持范围及限制；区分已实现、已验证和规划。
- `TODO.md`：唯一活动执行清单，保留可执行事项；定期将完成记录归档，保留追溯链接。
- `Roadmap.md`：阶段目标和退出条件，不复制勾选状态。
- `PRD/000-overview.md`：公共范围与模块索引；PRD-001～PRD-017 按模块组织；010、014 为撤销占位，017 定义独立 Tag。
- `decisions/`：取舍和选型；被替代的结论必须明确标注历史状态。
- `note/`：按专题维护有效笔记；正文反映当前约束，历史验证附日期，旧方案进入归档或明确历史区。
- `archive/`：可追溯历史资料，默认不读取为当前规范。

根 AGENTS 保持稳定背景、技术栈和索引；动态产品状态进入 PRODUCT。README 主要由用户维护或按明确要求更新，不自动作为内部记忆流水账。CHANGELOG 仅在明确更新版本时修改。

PRD 保留 F/A 编号，每个编号仅有一处主定义，跨模块使用链接。修改需求时核对依赖和公共约束；修改现有能力时核对 PRODUCT 和 TODO。不得把需求定义或示例 Demo 等同于正式功能验收。
