# 开发路线图

更新日期：2026-09-16。[普通 VSIX 决策](decisions/004-public-vsix-discovery.md)取代旧完整管理路线；阶段编号不等于版本。

| 阶段 | 目标 | 退出条件 |
| --- | --- | --- |
| M0 公开发现边界 | 本地 UI 宿主、未激活发现、上下文隔离 | 当前可见范围准确，Remote 窗口不混入远端；旧完整管理接口研究不再是门槛 |
| M1 保存与发现历史 | 正式组织仓库、真实历史缓存、迁移与恢复 | 消失保留，重现恢复；失败不批量标不可见；旧 Demo 不造历史 |
| M2 同步与投影 | generation、补读、两视图接入和多窗口防丢写 | 无跨 Profile 污染，历史项可整理，同步不覆盖组织数据 |
| M3 UI 收尾 | 可见性标记和统计，移除模拟启停与更新 | 当前/历史/未核验口径准确，保留用户认可的布局与拖动 |
| M4 验收 | A01–A06、A09、A15–A19、A21–A30 及局部 AC | 主题、性能、失败、重启、Profile、多窗口证据齐全 |
| M5 交付 | 普通 VSIX、包元数据与说明 | 正式入口无 seed/模拟管理；干净 Profile 安装升级验证 |

F10/F12/F13/F14 与 A07/A08/A10–A14/A20 撤销，不作为待实现或发布门槛。未实现不能因为换范围而标通过；旧执行清单见 [归档](archive/2026-09-16-before-public-vsix-scope.md)。

P1 收藏、自定义图标、Settings Sync 等后续提案须另定需求。Remote 聚合、其他 Profile 管理、规则/AI 分类与扩展包生成不在首版。启停、更新、导入导出和卸载不自动放回后续清单。

当前实现已覆盖 M1 主路径及 M2/M3 的代码接入；M0 的 Remote、M2 的运行中 Profile/双窗口和 M4 全量验收尚未结束。实现与证据见 [公开发现记录](note/public-discovery-implementation.md)。

PRD 已于 2026-09-17 [归档](PRD/README.md)。上述阶段对应的全部未完成任务、具体通过条件和 A/AC 编号映射统一维护在 [TODO](TODO.md)，本路线图不另设验收清单。
