# 开发路线图

更新日期：2026-09-14。采用用户本轮修订后的范围；阶段编号不是产品版本号。模块定义见 [PRD-000 索引](PRD/000-overview.md)。

| 阶段 | 目标 | 退出条件 |
| --- | --- | --- |
| M0：能力验证 | 完整安装清单、真实启用/更新状态、原生管理、Remote/Profile、灰显和 Tag 迁移 | 数据与原生清单对齐；直接调用及原生页面委托边界明确；旧 Demo 补 `tags` 不改变 Group；关键阻塞有报告，不能以部分检测替代全量要求 |
| M1：安装清单与组织 | 单一归属、原生树、本地状态、鼠标拖动插件和组、Tag 数据 | 禁用插件仍可见，拖动移动而非复制，重启保留唯一归属和 Tag |
| M2：原生管理与同步 | 启用/禁用、更新、原生外部安装/卸载只读同步 | 操作正确作用于目标，失败/重启状态准确，不假报成功；本插件不提供卸载入口 |
| M3：Dashboard | 正式概览、Tag 搜索筛选、鼠标批量整理和管理入口 | 真实统计与树一致，禁用灰显，Tag 多选为 AND 且与其他条件取交集，无重复分类数据 |
| M4：本地状态与质量 | assignments/tags 本地保存、失败恢复、A01–A11、A15–A25 及性能主题平台验证 | 全部当前 P0 验收有证据；撤销的 A12–A14 不计入；鼠标主流程可完成 |
| M5：交付准备 | 安装包、图标、授权和对外说明 | 可安装且说明准确；版本、提交和发布按用户明确授权 |

## 后续方向

- P1：收藏、自定义图标、Settings Sync、批量启停、自选其他 Profile 或未连接 Remote。
- P2：规则/AI 分类、Smart Groups、Extension Pack/推荐生成、使用统计；分类必须维持单一归属。

独立搜索、Tag 管理、组拖动排序、原生启停和更新、外部安装/卸载只读同步、状态同步和 Dashboard 已进入 P0。原生 TreeView 侧边栏与 Webview Dashboard 互补；Dashboard 可用 React（TypeScript）+ Vite，不需要独立后端。
