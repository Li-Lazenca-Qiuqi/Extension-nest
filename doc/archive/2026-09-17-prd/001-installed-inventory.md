## 1. 目标与需求

F01：通过本地 UI 宿主的公开扩展 API 自动发现可见扩展，合并本上下文历史记录。完整性仅对本次已成功取得的 API 快照而言，不宣称完整安装或全部已启用清单。不能按 isActive 过滤、不能调用 activate() 来探测。返回的内置或 VSIX 项不因无市场元数据而排除；未返回的 ID 不猜测。

## 2. 规则与交互

| 条目状态 | 条件 | 显示及行为 |
| --- | --- | --- |
| Visible | 同上下文最新成功快照含该 ID | 正常展示，刷新 lastSeenAt 与上次观测元数据 |
| NotVisible | 有真实发现历史，最新成功快照不含该 ID | 统一显示 Not found（本次未发现），保留记录 |
| Unverified | 只有旧组织 ID，或本会话尚无成功读取 | 统一显示 Not found（本次未发现）；快照未就绪仍显示 Loading/Error，不宣称当前安装 |

已知条目保持唯一 ID。首次发现进入 Ungrouped，若已有组织归属则恢复原归属；消失不删除、不移组、不清标签或顺序；再次发现恢复 Visible，不重复创建。NotVisible/Unverified 均可搜索、编辑 Tag、拖动排序、复制 ID、尝试原生导航。历史记录保留，Dashboard 默认 Visible，通过 All 或 Not found 查看；原生树明确选择组时展示该组全部记录。不自动清理历史，旧组织占位可通过预览确认清理。

禁用、卸载、宿主变化可能导致不可见，系统只报告观测事实，不推断 Disabled/Uninstalled。全局版本、启停范围和更新状态不采集。当前可见版本来自本次 manifest；历史项只能显示 Last seen version，图标不可读时回退占位。

首次加载和读取失败使用快照级 Loading/Error；已有成功快照失败用 Stale。失败、部分读取、持久化失败或上下文不符均不把缺项标 NotVisible，也不替换 lastSeenAt。成功空快照可以把本上下文曾发现项标为 NotVisible，但提示 No visible extensions，不是没有安装。

## 默认隐藏内置扩展（2026-09-17）

公开发现与真实历史仍保留所有 API 返回项；原生树、Dashboard、搜索和统计默认隐藏当前应用分发的内置 ID，包括对应历史项。设置 `extensionNest.showBuiltinExtensions` 默认为 false，开启后重新显示。隐藏不是删除，组织编辑不得覆盖隐藏项的归属、Tag 或顺序；删除整个组时其隐藏成员也回到 Ungrouped。

识别通过 `env.appRoot/extensions` 下随应用分发的 package.json 的 publisher/name，属于桌面发行目录适配，不是稳定 API 的 isBuiltin 字段，也不是 publisher 前缀判断。随应用分发的 ID 即使由用户目录中的更新版本提供仍隐藏；Microsoft 发布的普通用户扩展不因发布者被隐藏。不读取私有安装登记或状态数据库。目录读取失败保留旧状态并报错，可重试或开启显示内置扩展；其他发行版目录布局和应用不再分发的旧 ID 尚不保证识别。

界面仅区分本次发现和本次未发现，不向用户暴露历史证据是否存在；上述内部字段用于版本与时间真实性及兼容旧数据，不再各占一个统计或筛选入口。
