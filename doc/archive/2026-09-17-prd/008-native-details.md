## 1. 目标与需求

F08：按已知记录的规范化 ID 请求打开原生扩展页，支持 Copy ID。历史不可见和未核验项仍可请求导航，失败提供查找入口。

## 2. 规则与交互

点击图标或标题打开，Ctrl/Command 点击遵循多选；不提供自建 Details。白名单限制固定命令和已知 ID，不执行任意 URI/命令。原生命令按 ID 导航，不宣称严格绑定本地安装副本，也不保证目标已安装；可能打开市场页。

返回明确导航结果，如 Opened、Cancelled、Failed。页面打开、用户返回或 Promise resolve 都不表示启停/更新成功；取消恢复不报成功。失败提示和原生搜索按钮保留，Copy ID 可独立使用。

## 4. 验收条件

A23：当前项和历史项导航、缺失市场条目、取消、命令失败/恢复路径及 Copy ID 验证；无误报安装/管理成功，不改变组织数据。
