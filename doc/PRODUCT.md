# Extension Nest 产品说明

更新日期：2026-09-17。代码版本 0.2.1，publisher Lazenca。[决策 004](decisions/004-public-vsix-discovery.md)为当前产品范围；已接入公开发现、历史缓存和正式组织存储；本次交付本地 VSIX patch。

## 产品定位

普通 VSIX 扩展整理器：自动发现本地 UI 宿主公开可见的插件，保存发现历史，用唯一 Group 和独立 Tag 整理。此前发现、当前不可见的插件仍在原组并标 Not found；不可见不等于禁用或卸载。未激活的可见扩展也可发现，不主动激活插件。不承诺全部已启用/已安装、其他宿主或未曾发现的禁用插件可见。

## 关键流程

启动或刷新自动发现本地宿主可见 ID，与本上下文记录合并；首次新项进入 Ungrouped，已有项保留归属。曾发现项本次成功读取不再出现时显示 Not found；再次出现恢复 Visible。失败不批量标缺失，保留旧快照并标 Stale。

Dashboard 默认 Visible，All 或 Not found 可查看保留记录；原生树明确选择组时查看该组全部记录，历史项同样可编辑 Tag、拖动、排序、复制 ID。卡片使用单击/Ctrl 或 Command 多选，不用复选框；移组只拖动。组名校验、唯一归属、0.82 指针预览、组抓手和插入线等既有交互继续保留。

顶栏统计仅 All/Visible/Not found；Ungrouped 作为右侧 Group 筛选选项；All 为全部已知唯一 ID，不是已安装数量。分组标题显示当前筛选后的匹配数。没有 Enabled/Disabled/Updates、更新箭头或自动更新查询。版本只表示本次或上次观测，历史项注明 Last seen version。

点击图标/标题只请求原生页导航，可能打开市场页，不保证已安装或本地副本绑定；不宣告启停/更新成功。缺图标用占位，名称、描述和 Tag 按纯文本呈现。无导入导出、卸载、自建 Details、Move 弹窗或创建组引导。

## 支持范围与限制

当前包要求 VS Code ^1.137.0，正式最低版本以实测为准。首版 Windows 桌面本地 UI 宿主，不聚合 Remote/Web；连接 Remote 的窗口需验证仍在本地运行。Profile 存储与会话隔离必须验证，不伪造 API 未提供的实时 Profile 身份。

记录暂不可见可能由禁用、卸载、宿主或上下文变化造成，不能辨别原因。未曾发现的禁用项不会自动补齐。首次为空只表示未发现可见扩展。单写者锁以本扩展 globalStorageUri 为应用级锁域，不作为 Profile 身份：其他窗口（可能包括其他 Profile）只读，关闭写者后需重新加载只读窗口。只读窗口当次发现可查看，但不持久化。真实多窗口、缓存修复交互、三种主题与其他平台尚需验收。CLI、核心桥接、私有数据库均非本路线依赖。

## 未核验记录清理（2026-09-17）

Dashboard 顶部提供带数量的 Clear old records 按钮，原生侧边栏菜单和命令面板保留“Extension Nest: 清理旧记录”。只读、读取未成功或没有候选时面板按钮不可用。成功刷新后预览无真实发现历史的 Unverified ID、分组和标签；用户多选并确认精确 ID 后永久删除这些组织归属、Tag 和顺序记录，不创建备份，不提供恢复功能。NotVisible、当前可见项和隐藏的内置项不列入候选。分组本身与真实发现历史保留，不卸载实际扩展。

确认对话框明确说明永久删除且不可恢复。对话框期间元数据变化或条目被真实发现，整批操作取消；删除写入失败保留原状态。正式组织键继续存在，重启不会从旧 Demo 再次迁移已清理条目。

2026-09-17：用户界面合并原 NotVisible 与 Unverified，统一为 Not found（本次未发现）；树、卡片、统计和筛选口径一致，不显示来源区别。正常卡片不再显示 Visible 标签。后台保留是否存在真实发现证据，防止旧占位伪造版本/时间；旧记录清理的删除范围不因文案合并扩大到真实发现历史。

2026-09-17：Dashboard 默认打开 Visible 筛选，仅展示本次发现的插件；用户仍可点击 All 或 Not found 查看保留记录。原生树明确选择分组时查看该组全部记录。
