# Extension Nest 产品说明

更新日期：2026-09-15。当前版本：0.1.2，本地交互 Demo。版本依据 package.json；本版本修复默认分组展示和卡片拖动预览，保留独立 Tag；不提供导入导出和卸载。验证记录包含 2026-09-12 至 2026-09-15。

## 产品定位

在 VS Code 内按唯一分组整理扩展，并用独立 Tag 做搜索和筛选。分组使用原生 Explorer 侧边栏，Dashboard 使用编辑器中的紧凑卡片，不额外创建网页侧边栏。

## 现有功能

| 模块 | 0.1.2 现状 | 能力边界 |
| --- | --- | --- |
| 分组与归属 | 创建、改名、删除组，鼠标移组，唯一归属 | 仅操作示例数据；移动分组不改变标签 |
| Tag | 单个编辑、批量替换、多 Tag AND 筛选、标签名搜索 | 只改标签，不改变 Group；单个编辑与筛选已在 VS Code 实测，批量通过逻辑测试 |

| Dashboard | 默认按 Group 展开的紧凑卡片分区、搜索、统计筛选、复选选择及管理菜单 | Tag 筛选已接入 Demo；真实扩展清单尚未接入 |
| 插件管理 | 模拟启用、禁用和更新，禁用灰显 | 不操作用户真正安装的扩展；本插件不提供卸载入口；对 VS Code 外部安装/卸载只读同步尚未接入 |

| 分发 | 可构建 VSIX，在扩展开发宿主运行 | 尚未发布 Marketplace |

## 关键流程

1. 在 VS Code 打开 Demo 的原生分组视图或 Dashboard。
2. 点击原生组筛选卡片，使用卡片上的分组入口移动插件；一个插件只有一个组。
3. 点击示例状态或管理菜单，查看灰显、统计与原生树同步变化；当前管理动作只作用于演示数据。
4. 在卡片编辑多个 Tag，点击 Tag 或在搜索框输入标签名筛选；可同时应用组、状态和多个标签条件。
5. 重启后恢复 Demo 状态；配置文件交换不属于当前流程。

安装和启动步骤见 [README](../README.md)。

## 支持范围

- 当前包要求 VS Code 1.137.0 或更新版本；只记录本机 Windows、VS Code 1.137.0 的运行验证，不等同于所有后续版本均已测试。
- 初始数据为 14 个示例扩展，并非本机安装清单。
- macOS、Linux、WSL/SSH、跨 Profile 和多窗口并发的正式支持仍待验证。
- 无独立后端；演示启停和更新不会修改真实插件。对 VS Code 外部安装或卸载的只读状态同步尚未接入。
