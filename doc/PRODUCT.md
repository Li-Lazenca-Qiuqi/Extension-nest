# Extension Nest 产品说明

更新日期：2026-09-15。当前版本：0.2.0，本地交互 Demo。版本依据 package.json；本版本增加分组双栏、批量展开收起和市场图标，发布者改为 Lazenca，保留独立 Tag；不提供导入导出和卸载。验证记录包含 2026-09-12 至 2026-09-15。

## 产品定位

在 VS Code 内按唯一分组整理扩展，并用独立 Tag 做搜索和筛选。分组使用原生 Extension Nest 侧边栏，Dashboard 使用编辑器中的紧凑卡片，不额外创建网页侧边栏。

## 现有功能

| 模块 | 0.2.0 现状 | 能力边界 |
| --- | --- | --- |

| Dashboard | 默认按 Group 展开的紧凑卡片分区、搜索、统计筛选、单击/Ctrl 多选及管理菜单；指针拖动时目标组整体高亮 | 高亮与移动已在内置浏览器验证；VS Code 主题效果待人工确认；真实扩展清单尚未接入 |

## 关键流程

分组展开/收起：顶部提供 Expand all groups 与 Collapse all groups 图标按钮，包含 Ungrouped；各组标题仍可单独切换，单栏与双栏共享当前面板的折叠状态。

分组双栏视图：顶部 Two-column groups 图标按钮可切换分组左右两栏，按原分组顺序从左到右排列；每组保留独立标题、卡片与折叠功能。默认沿用单栏分区，面板宽度不超过 760px 时自动回到单栏；选择只保留在当前面板会话。

顶部工具栏：标题、统计、搜索、分组/标签筛选与操作按钮在宽面板中共用一行；窄面板自然换行。移除重复的列表标题，分组筛选仍显示当前组。统计按钮互斥选中，默认 All；All 清除所有筛选并恢复完整清单，此时不显示 Filters / Clear 栏（卡片选择仍可显示操作栏）；切换统计项时重置分组和状态条件，避免 Ungrouped 与启停条件残留叠加，不再提供重复状态下拉框；Tags 菜单宽度随最长标签自适应并限制最大宽度，支持点击外部或 Escape 收起。不提供 Check updates 按钮，打开面板时读取演示状态中的更新信息，真实联网更新查询尚未接入。

卡片布局：不重复显示分类名称；Enabled/Disabled 使用紧凑文字按钮，与右侧版本号处于同一行，版本左侧的更新按钮保留原配色和边框，仅显示箭头。标签非空时紧接启停按钮右侧，与版本号保持同一行；标签过多可横向滚动，每个标签文字左侧显示 10px 标签图标。启用按钮为绿色底色，禁用按钮为中性色。移组和标签编辑通过右上角管理菜单进入。仅点击插件图标或标题文字请求打开该 ID 的 VS Code 原生扩展页，发布者和标题旁空白用于选择或拖动；不提供自建 Details 弹窗或 Details 菜单项。

插件图标：Dashboard 使用 30px 真实图标，宿主优先读取已安装扩展声明的本地图标，缺失时从 Marketplace 获取；浏览器 Demo 直接读取 Marketplace 图片。禁用图标灰显，加载失败保留字母占位；图标使用会话缓存，不改变示例清单或启停状态。

分类配色：Dashboard 使用各组已保存的颜色绘制标题分割线与卡片顶部 3px 色线；新组沿用自动配色，Ungrouped 使用主题中性色。移组后色线跟随新组，拖放高亮仍使用 VS Code 主题色。

原生侧边栏使用彩色 layers 分类图标，已启用插件的 extensions 图标跟随所属组，禁用插件保留灰色 circle-slash，Ungrouped 使用中性色 inbox。六色色板通过 extensionNest.group.* 主题颜色与 Dashboard 共享，高对比度主题使用更清晰的对应颜色。原生树不绘制卡片顶部色线。

1. 在 VS Code 打开 Demo 的原生分组视图或 Dashboard。
2. 点击原生组筛选卡片，使用卡片上的分组入口移动插件；一个插件只有一个组。
3. 点击示例状态或管理菜单，查看灰显、统计与原生树同步变化；当前管理动作只作用于演示数据。
4. 在卡片编辑多个 Tag，点击 Tag 或在搜索框输入标签名筛选；可同时应用组、状态和多个标签条件。
5. 重启后恢复 Demo 状态；配置文件交换不属于当前流程。

安装和启动步骤见 [README](../README.md)。

## 支持范围

- 当前包要求 VS Code 1.137.0 或更新版本；只记录本机 Windows、VS Code 1.137.0 的运行验证，不等同于所有后续版本均已测试。
- 初始数据为 14 个示例扩展，并非本机安装清单。
- macOS、Linux、WSL/SSH、跨 Profile 和多窗口并发的正式支持仍待验证。
- 无独立后端；演示启停和更新不会修改真实插件。对 VS Code 外部安装或卸载的只读状态同步尚未接入。
